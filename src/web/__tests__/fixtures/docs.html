retry(fn, options)

Calls fn until it succeeds. Pass `raw` names in Ctrl+C style.

Example

const result = await retry(() => fetch(url), {
  attempts: 3,
  on_error: (err) => console.log(`failed: ${err}`),
})

// <T> is inferred &amp; kept

From a shell:

$ npm install retry
$ echo '```'
